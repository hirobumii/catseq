# CatSeq documentation

The documentation is organized by audience and subject:

- [`user/`](user/) contains CatSeq installation, concepts, hardware-facing
  usage, advanced topics, and the Python interface reference.
- [`dev/`](dev/) contains device documentation: RTMQ architecture and QCtrl
  hardware references. Here, `dev` means **device**, not development.
- [`development/`](development/) contains compiler/runtime design documents,
  implementation plans, performance records, and migration work.
- [`adr/`](adr/) contains accepted architecture decision records.

New project-development documents belong in `development/`; do not mix them
into the device reference directory.
